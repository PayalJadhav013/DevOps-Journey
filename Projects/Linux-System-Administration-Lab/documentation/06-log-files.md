# Part 6 — Logs

## Objective

Practice Linux log management by locating system log files, viewing log contents, monitoring logs, and searching log entries using common Linux commands.

---

## 1. Navigate to the Log Directory

```bash
cd /var/log/
```
The `/var/log/` directory contains logs generated by the Linux operating system and various services.

Check the current directory:
```bash
pwd
```
Output:
```text
/var/log
```
## 2. List Log Files
```bash
ls
```
This command lists the files and directories available inside `/var/log/`.

For detailed information:
```bash
ls -l
```
For sorting by modification time:
```bash
ls -ltr
```
## 3. View Log File Contents

Use cat to display the complete contents of a log file:
```bash
cat <log-file>
```
For example:
```text
cat messages
```
Note: The exact log files available can vary depending on the Linux distribution and configuration.

## 4. View Large Log Files

For large log files, use:
```bash
less <log-file>
```
Example:
```text
less messages
```
Useful keys inside less:

- `Space` → Next page
- `b` → Previous page
- `/keyword` → Search
- `q` → Quit

## 5. View the Last Lines of a Log
```bash
tail <log-file>
```
To view the last 20 lines:
```bash
tail -20 <log-file>
```
Example:
```text
tail -20 messages
```
## 6. Monitor Logs in Real Time
```bash
tail -f <log-file>
```
The -f option continuously monitors the log file and displays new entries as they are added.

Press:
```text
Ctrl + C
```
to stop monitoring.

## 7. View System Logs Using journalctl

On systems using systemd, logs can also be viewed using:
```bash
journalctl
```
View the most recent logs:
```bash
journalctl -n
```
View logs in real time:
```bash
journalctl -f
```
View logs for a specific service:
```bash
journalctl -u httpd
```
## 8. View Recent Logs for a Service

For the Apache HTTP Server:
```bash
journalctl -u httpd -n
```
This displays the most recent journal entries related to the httpd service.
